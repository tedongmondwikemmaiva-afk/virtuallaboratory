# 📖 Virtual lab project: Desktop version<a name="about-project"></a>

Virtual laboratory is a desktop application designed to provide secondary schools students with interactive virtual science laboratory experience.The project aims to simulate real laboratory activities digitally,starting with chemistry experiments, to improve practical learning and accessibility.

**[Desktop virtual lab Project]** is c#, javascript and mysql project

## 🛠 Built With <a name="built-with"></a>

### Tech Stack <a name="tech-stack"></a>

- c#
- Javascript
- my SQL


### Key Features <a name="key-features"></a>
- **Interactive virtual lab environment**
- **Chemistry experiment simulation**
-**Virtual lab equipment**
-**Step-by-step experiment guidance**

## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:

- IDE( integrated development environment) such as Visual Studio 
- A 3D modeling and animation software such as blender.
- version control such as GIT & GITHUB
- UI design such as figma 
- Game engine such as unity
### Setup

Clone this repository to your desired folder:

```sh
  cd virtuallaboratory
  git clone https://github.com/tedongmondwikemmaiva-afk/virtuallaboratory.git
```

### Install

Install this project with:

```sh
  cd virtuallaboratory
  npm install
```

### Usage

To run the project, start the html file on live server or run normally from local directory

### Run tests

To run tests, run the following command:
```sh
  npx hint .
  npx stylelint "**/*.{css,scss}"
```

### Deployment

You can deploy this project using:

```sh

```
